## Problem

Learn to build for the web from the ground up: structure, style and behaviour, each done by hand and published.

## Approach

Each lab focused on one skill, and pages were checked with the W3C validator before they were published.

| 3 | Semantic markup of book excerpts, validated |
| 4 | An accessible form rebuilt from a paper form: fieldsets, labels, radio buttons, checkboxes and menus |
| 5 | Code hygiene: cleaning up messy HTML for meaning, structure and alt text |
| 6 | Styling a data table in CSS, with NASA data on four planets |

## Results

The final project added a map with a location marker, a jQuery image slider, and a flexbox layout with breakpoints that
adapts from phones to wide screens. The data-table lab is the one I iterated on most, and it shows what CSS alone can
do with a plain table.
