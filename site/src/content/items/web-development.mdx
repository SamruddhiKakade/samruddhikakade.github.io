## Context

Ten websites for ITMD 361, Fundamentals of Web Development, covering structure in HTML, presentation in CSS and
behaviour in JavaScript and jQuery. Seven labs each practised one technique, and three projects extended a single
multi-page site over the term.

## Approach

Each lab isolated one technique, and every page was checked with the W3C HTML and CSS validators. The projects added
structure, then styling, then interactivity to one site.

## Contribution

- Implemented seven labs and three project stages in HTML, CSS and JavaScript, each page checked with the W3C
  validators.
- Developed a form with labelled text fields, radio buttons, checkboxes, a menu and a text area, grouped in fieldsets
  with legends, from a paper-form sample.
- Styled a single table of seven NASA data fields for Mercury, Venus, Earth and Mars in CSS without a framework, with
  planet images carrying text alternatives and row highlighting on hover.
- Developed a centred top navigation and a fixed side navigation in CSS, leaving the HTML unchanged.
- Added to the final project an embedded map with a marker, a jQuery image slider and media queries at 900 and 1200
  pixels that scale headings and spacing.

<More label="Detail of the final project">
- **Map.** A Google map centred on the Illinois Institute of Technology campus, with a marker and an information
  window that opens on click.
- **Image slider.** Three images with left and right arrow controls. jQuery animates each move over 500 milliseconds
  and cycles the images in a loop.
- **Media queries.** One query below 900 pixels and one above 1200 pixels change heading sizes, card corner radius and
  spacing.
</More>

## Lessons learned

- **Structure and presentation can be separated.** Lab 7 changed only the CSS, and the same HTML produced both the top
  and the side navigation.
- **Meaning belongs in the markup.** Semantic tags and descriptive alt text, practised in Lab 5, are what search
  engines and screen readers read.
