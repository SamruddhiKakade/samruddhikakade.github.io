## Problem

Understand machine-learning methods by building them: write the maths as code instead of calling a library's fit.

## Approach

- **Regularisation:** ridge and lasso regression across regularisation strengths, including degree-5 polynomial
  features, on real car data (with scikit-learn).
- **Logistic and softmax regression:** sigmoid, softmax, cross-entropy loss, and training by batch gradient descent
  and mini-batch stochastic gradient descent, written in NumPy.
- **Perceptron:** a perceptron with three activation functions, trained on handwritten digits, written in NumPy.

## Calculations

Logistic regression predicts $\hat y = \sigma(w^\top x + b)$ with $\sigma(z) = 1/(1+e^{-z})$, and learns by gradient
descent on the cross-entropy loss:

$$
L = -\frac{1}{n}\sum_{i=1}^{n}\bigl[y_i \log \hat y_i + (1-y_i)\log(1-\hat y_i)\bigr],
\qquad
w \leftarrow w - \eta\,\frac{1}{n}\sum_{i=1}^{n}(\hat y_i - y_i)\,x_i
$$

<More>
Softmax regression generalises this to several classes: $\hat y_k = e^{z_k} / \sum_j e^{z_j}$, with the same kind of
gradient step per class. Mini-batch stochastic gradient descent takes each step on a small random batch instead of the
whole dataset, which is faster and adds useful noise.
</More>
