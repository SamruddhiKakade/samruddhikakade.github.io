## Context

Fake news spreads through headlines that repeat or contradict each other. Given a headline already known to be fake and
a new one, the task was to decide whether the new headline agrees with it, disagrees with it, or is unrelated. The
labels were heavily uneven, so accuracy has to be read against a baseline.

<More label="Why the baseline matters">
Unrelated pairs are 68.5% of the labelled data, so a model that always answered "unrelated" would be right 68.5% of
the time. Every accuracy on this page is read against that figure.
</More>

## Approach

A text pipeline turned each headline pair into word counts, and four classifiers were compared by five-fold
cross-validation. The best of the four was refitted on all labelled pairs and used to label the unlabelled set.

<Flow
  label="The classification pipeline"
  steps={['Clean and lowercase', 'Tokenise and lemmatise (NLTK)', 'Word counts per headline pair', 'Scale features', 'Compare four models by five-fold cross-validation', 'Refit the best on all data and label the test set']}
/>

<More label="Pipeline and model details">
- Both headlines of a pair were joined into one text before counting, so each pair became a single vector of word
  counts.
- The tokeniser runs inside the word-count step, so cleaning and counting stay in one pipeline.
- Features were scaled without centring, which keeps the large word-count matrix sparse and fast to train on.
- The four models were logistic regression, a random forest, a decision tree and a linear support vector machine, all
  with scikit-learn's default settings.
</More>

## Contribution

- With a partner, developed the text pipeline (cleaning, tokenising and lemmatising with NLTK, word counts and feature
  scaling), compared four classifiers by five-fold cross-validation and selected the random forest.
- Co-wrote the project report and presentation slides.

## Findings and limitations

The random forest reached 0.761 mean cross-validated accuracy, 7.6 percentage points above the 68.5% majority-class
baseline, and was the most accurate of the four models.

<More label="Variation across folds and limitations">
- The report gives each accuracy with the standard deviation of the five fold accuracies: random forest 0.002, decision
  tree 0.007, logistic regression 0.008, linear support vector machine 0.006.
- Only accuracy was reported. Per-class recall and F1 were not computed, so how well the 6,606 disagreeing pairs were
  found is not known.
- The word-count vocabulary and the scaler were fitted on all labelled pairs before cross-validation, so the fold scores
  may be optimistic; the size of the effect was not measured.
- Counting the words of both headlines together ignores which words came from which headline, and no model settings
  were tuned.
- The unlabelled pairs had no published answers, so the accuracy is a cross-validation estimate, not a test-set score.
</More>
